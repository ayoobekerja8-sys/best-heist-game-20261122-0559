VAULTLIGHT is a top-down stealth heist: you play Wren, slipping through the Meridian Gallery at midnight. Guards sweep vision cones across the halls, security cameras watch the galleries, and paintings, display cases and the vault's Star of Meridian are all there for the taking. Every sighting and every noise feeds the alarm meter, so use cover, shadows and distractions to get in, take the loot and reach the skylight before lockdown.

How to run: python3 -m http.server inside game/ then open http://localhost:8000
